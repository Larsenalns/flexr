FlexR — javadoc artifact
========================

This module's documentation is written as javadoc in its sources, and is published in the
-sources.jar. The Maven Central repository requires a -javadoc.jar to exist for every artifact,
so this file ships in that jar; it points to the real documentation instead of duplicating it.

Where to read the API:
  - the -sources.jar of this artifact (javadoc for every public member), and
  - docs/GUIDE.md in the project repository (integration, R8, theme, threading).
